# LaTeX compilation manual

1. Install a supported LaTeX engine following its official platform instructions.
2. Confirm the compiler is available from the shell.
3. Compile a minimal test document in an isolated directory.
4. Configure any machine-specific command paths outside the shareable skill files.
5. Follow each project's existing build and generated-artifact conventions.

Do not publish local paths, usernames, private documents, package caches, or license information.
