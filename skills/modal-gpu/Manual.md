# Modal GPU manual

1. Create a Modal account and install its official client tools.
2. Authenticate locally with the provider-supported flow.
3. Store authentication only in local provider configuration or a secret manager.
4. Create a small test workload and verify its logs and outputs.
5. Set a budget or usage limit appropriate to your account before using expensive hardware.

Do not commit authentication configuration, workspace information, private datasets, deployment URLs, or job logs.
