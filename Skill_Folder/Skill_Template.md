# Skill Template

Use this file for the reusable instructions that define one clear capability.

## Scope

State when the skill applies and what it does not cover.

## Operating rules

- Preserve the user's intended scope.
- Prefer read-only operations when they answer the request.
- Require explicit authorization before external mutations.
- Never expose credentials, identifiers, private URLs, or personal data.

## Local configuration

Name needed environment variables and required permissions, but never include their values. Direct the user to `Manual.md` for setup.
