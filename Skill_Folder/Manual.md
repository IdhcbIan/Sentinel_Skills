# Manual

1. Copy this folder and rename the skill document to match the skill name.
2. Write only general, reusable instructions in the skill document.
3. Explain how the recipient gets tokens or credentials through the official provider in this manual.
4. Store credentials locally in environment variables, a secret manager, or an ignored configuration file.
5. Before sharing, verify that neither file contains tokens, account identifiers, private URLs, personal data, or local paths.
